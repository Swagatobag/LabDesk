NABL / ISO 15189

Westgard Multi-Rule Decision Guide

1-2s
Warning Rule (Random / Systematic)

One control observation exceeds Mean ± 2SD. Inspect other rules before rejecting run.

1-3s
Reject Run — Random Error

One control exceeds Mean ± 3SD. Do not release patient results; rerun control & check reagent/pipetting.

2-2s
Reject Run — Systematic Error

Two consecutive controls exceed +2SD or both exceed -2SD. Recalibrate analyzer or replace reagent lot.

R-4s
Reject Run — Random Error

Range between two controls in the same run exceeds 4SD (e.g., Level 1 > +2SD and Level 2 < -2SD).

4-1s
Reject Run — Systematic Shift

Four consecutive control results exceed +1SD or -1SD on the same side of the mean.

10-x
Reject Run — Systematic Bias

Ten consecutive control values fall on the same side of the mean (above or below).

☣️ Bio-Medical Waste (BMW) Management Rules

Color-coded segregation matrix for diagnostic laboratories per BMW Management Rules.

YELLOW BAG / BIN

Infectious & Anatomical Waste (Incineration / Deep Burial)

  • Blood-soaked cotton swabs, gauze, bandages & dressings
  • Human anatomical / tissue biopsy waste
  • Discarded blood bags & clinical body fluid pouches
  • Microbiology culture plates, stocks & specimen swabs (pre-treated)
  • Expired or discarded cytotoxic/pharmaceutical medicines

RED BAG / BIN

Contaminated Recyclable Plastics (Autoclaving / Microwaving)

  • Used plastic Vacutainers (EDTA, Citrate, Fluoride, Plain)
  • Disposable syringes (without needles), micropipette tips & cuvettes
  • Contaminated gloves, urine containers & sputum cups
  • IV sets, catheters, blood transfusion tubing
